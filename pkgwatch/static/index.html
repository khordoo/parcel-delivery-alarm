Pushover (iPhone)

Setup steps
  1. Install Pushover on the iPhone (one-time ~US$5 after a 30-day trial) and sign in.
  2. On pushover.net, copy your User Key from the dashboard.
  3. “Create an Application/API Token” (name it PkgWatch) and copy the API Token.
  4. Paste both above. They go to the macOS login Keychain, never to disk in plain text.
  5. iPhone: allow Pushover Critical Alerts (Settings → Notifications → Pushover) so emergencies ring through Silent/Focus.
  6. Press “Test both channels”, acknowledge on the phone, and confirm the Mac alarm stops too.
